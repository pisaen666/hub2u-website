# รายการข้อมูลที่ต้องเติมก่อนเปิดเว็บ

เนื้อหาครบทั้ง 9 หน้าแล้ว (ไฟล์ 01-09) ช่อง [ใส่...] ด้านล่างยังว่างอยู่

## A. ข้อมูลติดต่อ (ใช้หลายหน้า)
- [ ] เบอร์โทร (หน้า 01, 08)
- [ ] ไลน์ไอดี และรูป QR ไลน์ (หน้า 08 และปุ่มแอดไลน์ทุกหน้า)
- [ ] เวลาทำการ (หน้า 01, 08)
- [ ] ตำแหน่งจุดรวมของในตลาด (หน้า 08)

## B. ข้อมูลการสั่งซื้อ
- [ ] ค่าส่ง (หน้า 02, 03)
- [ ] เวลารับออเดอร์ (หน้า 02, 03)
- [ ] รอบส่ง และวันหยุด (หน้า 03)
- [ ] วิธีจัดการเมื่อของที่สั่งหมด (หน้า 02)
- [ ] เงื่อนไขยกเลิกออเดอร์และคืนเงิน (หน้า 02) ลูกค้าจ่ายล่วงหน้า จึงสำคัญมาก

## C. ร้านค้าและไรเดอร์
- [ ] ค่าธรรมเนียมการขายของร้านค้า (กี่เปอร์เซ็นต์) (หน้า 05)
- [ ] ร้านค้าได้รับเงินทุกกี่วัน (หน้า 05)
- [ ] ค่ารอบต่อเที่ยวของไรเดอร์ (หน้า 06)
- [ ] ไรเดอร์ได้รับเงินทุกกี่วัน (หน้า 06) ห้ามเขียนว่า "ทุกเย็น" จนกว่าจะยืนยัน
- [ ] เอกสารที่ร้านค้าและไรเดอร์ต้องใช้สมัคร (หน้า 05, 06)
- [ ] ลิงก์สมัครร้านค้า และลิงก์สมัครไรเดอร์ (หน้า 05, 06)

## D. ลิงก์และแบรนด์
- [ ] ลิงก์เว็บแอปสั่งของที่จะใช้จริง (หน้า 09 และปุ่มสั่งของสดทุกหน้า)
- [ ] ไฟล์โลโก้จริง
- [ ] เรื่องราวว่าทำไมถึงทำ Hub2U (หน้า 01, 07)
- [ ] รูปจริงของเจ้าของ ทีมงาน และตลาด (ถ้ามี)

## E. ต้องยืนยันว่ายังเป็นจริงในแอป
- [ ] คืนเงินส่วนต่างของที่ขายตามน้ำหนัก (หน้า 01, 02)
- [ ] ติดตามสถานะออเดอร์ผ่านลิงก์ส่วนตัว (หน้า 01, 02)
- [ ] ร้านค้าเรียกไรเดอร์ส่งของลูกค้าตัวเองได้ และมี QR ประจำร้าน (หน้า 05)
- [ ] ตรวจเอกสารและรูปถ่ายก่อนเริ่มงาน (หน้า 04, 07)
- [ ] ร้านค้าไม่เห็นชื่อ เบอร์ ที่อยู่ลูกค้า (หน้า 04, 05, 07)
- [ ] ยังไม่เปิดให้ลูกค้ามารับของที่ตลาดเอง (หน้า 08)
- [ ] แอปเช็กระยะ 7 กม. ให้อัตโนมัติไหม (หน้า 03)

## F. ตอนสร้างเว็บจริง ผมต้องแก้ในไฟล์ออกแบบเดิม
- เปลี่ยนคำว่า "จ่ายเงินทุกเย็น" ในไฟล์ออกแบบเดิม ที่ยังไม่ได้ยืนยัน
- เก็บรูปภาพเป็นไฟล์ในเว็บ ไม่ดึงจากลิงก์ของ Google
- ตัดรูปโปรไฟล์วงกลมในส่วนหัว ตัดฟอร์มส่งข้อความหน้าติดต่อเรา
- เชื่อมลิงก์ทุกปุ่ม
